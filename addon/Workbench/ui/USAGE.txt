镜像幻化

在 FaustLauncher 的插件设置中打开工作台，也可以双击 Workbench 目录中的 open_workbench.cmd。工作台优先使用启动器自带的 Python。

人格与对应外观

在「规则集」中选用要出战的人格规则，再到「人格池」点「添加人格」。当此外观目录中有人格的对应外观时，来源菜单默认选中「当前人格的对应外观」。选中外观并加入池中，实际出战人格抽中这个对应外观时，插件自动使用该组合的演出适配。同一人格可以有多个对应外观，每项都可以单独设置权重。

在来源菜单选择「全部来源」可以继续混搭其他外观。也可以按章节、角色筛选，或输入名字、资源 ID 搜索。全局池与角色池可照常使用，实际出战人格和抽中的外观共同决定是否启用对应演出。

已有的形态组池条目会转换成组内第一阶段的普通外观。同一个外观在池中出现多次时合并权重。旧组原本停用时，其条目保留零权重。工作台在打开旧方案时也会处理这些条目。

人格池与演出

人格池列出每个外观的权重和抽中概率。右键可以移动条目、移出池子、设置图片或只抽中该条目。增减池成员后，请重启启动器和游戏，以便准备新增外观的资源。

「抽取编排」可以分别为攻击、拼点和守备选择加权随机、加权轮抽或池中顺序。加权轮抽的权重影响轮内先后；顺序抽取会跳过零权重条目。

若个别外观的特殊拼点动画导致游戏卡住，默认已禁用特殊拼点动画。需要恢复时，在插件目录的「随机设置.json」中把 `disable_special_clash` 改为 `false`。

「形态配置」用于支持内部形态的人格，可沿用原生行为，也可设置守备次数、理智、血量或固定阶段。阶段 0 为基础形态，能显示哪些阶段取决于该人格的资源。

「演出记录」支持按角色、事件或原因查找最近的战斗记录。「准备状态」显示资源准备进度和核心读取规则的状态。

「方案管理」可保存、导入、导出和读取整套人格池与规则集。读取前会自动备份当前配置。修改池权重后，请等待页面显示「已自动保存」，再导出方案。

首次使用特效编辑器

打开工作台后会在后台准备资源读取组件。工作台优先使用启动器已有的解析、纹理和音频库。使用 64 位 Python 3.9 的启动器缺少这些库时，会从 Python 官方包仓库自动下载经过校验的组件，共约 7.31 MB，缓存到当前用户的本机目录。首次补齐需要联网，后续可以复用。

选中外观后，编辑器会从游戏已经下载的资源中读取动作、时长及特效轨道，结果缓存在本机。游戏更新资源后会重新读取。若提示缺少此外观，请先在游戏中下载对应资源，然后点「读取本机资源」重试。战斗覆盖需要的基础动作表随插件提供。
