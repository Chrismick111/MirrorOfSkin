# 镜像幻化（Mirror of Skin, MOS）

适用于 [FaustLauncher](https://github.com/f0lkskill/FaustLauncher) 的《边狱巴士》(Limbus Company) 人格外观随机插件。
通过 WarpHook 注入原生 DLL，在战斗中替换罪人外观、随机切换人格，并按原生触发条件播放 Boss 语音与气泡。

## 安装插件

当前可下载的正式版为 **1.4.4**。在 Windows 64 位系统上打开 FaustLauncher，确认已安装并启用 WarpHook。下载下表第一项，在启动器中选择「从本地安装」，选中 ZIP。安装完成后，从启动器托盘打开「镜像幻化 → 人格、概率与演出设置」。

| 下载 | 用途 |
| --- | --- |
| [1.4.4 启动器安装包](https://github.com/Chrismick111/MirrorOfSkin/releases/download/v1.4.4/MirrorOfSkin-1.4.4-no-images.zip) | 首次安装或手动更新。公开版不含头像，可在工作台获取资源。 |
| [1.4.4 兼容安装包](https://github.com/Chrismick111/MirrorOfSkin/releases/download/v1.4.4/MirrorOfSkin-1.4.4-no-images-store.zip) | 启动器解压上一个文件失败时选用。两个包的插件内容相同，安装其中一个即可。 |
| [1.4.4 工作台更新包](https://github.com/Chrismick111/MirrorOfSkin/releases/download/v1.4.4/FaustRandomIdentity-WarpHook.zip) | 供旧版工作台的自动更新功能读取。 |

手动安装时，解压标准包，将其中 `MirrorOfSkin` 文件夹的内容放入 `FaustLauncher/addons/MOS/`。请确认 `addon_info.json` 直接位于 `addons/MOS/` 下。已经安装的用户请沿用原插件目录，避免启动器同时加载两份。

## 第一次设置外观

1. 打开工作台，选择要配置的规则集。可以对全部罪人、某个罪人或单个人格设置外观池。
2. 点「添加人格」，按角色、章节或名称找到外观，点击该行的加号。只想固定使用一个外观时，可以在池中右键该外观，选择「仅抽中此人格」。
3. 要随机使用多个外观，就把它们加入同一个池，并调整各自权重。到规则集页面启用对应规则；只切换到某个规则集编辑，不会自动启用它。

外观替换保留佩戴者的技能、伤害和战斗规则。能看到哪些攻击、拼点、守备或闪避画面，取决于模型实际具备的动作以及作者提供的映射。

## 导入本地外观

点击工作台右上角的圆形下箭头，或在「添加人格」窗口选择「导入外观（可多选）」。按住 Ctrl 逐个点选文件，按住 Shift 可连续选择。工作台会显示当前包名、文件序号和总进度。某个包导入失败时，后续文件会继续处理。完成后展开明细即可按包查看结果，再到「添加人格 → 外来人格」把需要的外观加入规则集。

1.4.0 会优先读取当前外观及所属包 README 中的作者全称和模组链接。人格池卡片上可直接点击演示视频，其他文字链接可在「更多链接」中查看。**从旧版升级后，请重新导入原压缩包一次**，即可补齐或更新现有卡片的署名和链接，并保留原外观编号与权重。

文件选择框支持 ZIP、7z、RAR，也可选择 `.bundle` 模型、`.carra2` 替换资源或 `.bank` 语音库。语音库需要与外观建立绑定。导入私服模组时，工作台结合包内人格声明、身体图像和动作轨选择作者制作的外观。已验证的形式包括独立角色模型、替换原版身体帧，以及逐枚硬币切换模型。只有技能数值、被动或 E.G.O 配置的模组会提示属于玩法改动包；单独的依赖 DLL 不能生成外观。

**导入 Carra2 补丁。** 选择原始 `.carra2` 文件，或直接选择作者同时附带底包的完整压缩包。1.4.2 会按对象实际引用的脚本匹配类型，即使作者调整了类型编号，也能从同包资源或本机已下载的游戏资源恢复匹配的定义。提示缺少游戏底包时，请先下载对应的游戏资源，或改选作者的完整包。

**语音和气泡分别判断。** 导入明细会区分「已检出」「已绑定」和「沿用基础模型语音」。仅检出音频或台词时会保留本体对应表现。已绑定的外观语音进入播放状态后才接管该佩戴者的原声；外观气泡成功显示后才隐藏对应的本体气泡。其他单位各自使用自己的声音和台词。

### Mod 包（自描述）

除了在文件选择框里逐个导入压缩包，也可以把作者整理好的 Mod 包文件夹放到启动器的 `mods` 目录（与 `addons` 同级）。打开「添加外来人格」时，工作台会列出扫描到的包，显示名称、版本和图标，点击「导入」即可。

每个包目录至少包含：

| 文件 | 作用 |
| --- | --- |
| `mod_info.json` | 启动器读取的名称、版本、依赖与启用开关；`settings.enable` 为 `false` 时工作台不会导入。 |
| `mos-mod.json` | MOS 的导入声明：`schema`、`id`、`strategy`、`bundles`，可选 `identity`、`icon`、`recipe`。 |
| `icon.png` | 包卡片图标；未声明 `identity` 时也作为该包唯一产出外观的头像。 |
| `bundles/*.bundle` | 实际导入的模型文件，必须在 `mos-mod.json` 中逐个列出，未列出的文件不会导入。 |

目前 `schema` 为 `1`，`strategy` 仅支持 `bundles`。包目录名不必与 `id` 相同，但 `id` 必须唯一。仓库中的 `mods/roland` 是罗兰示例包（模型文件不随仓库分发）。

### 善意的巡礼

[下载「善意的巡礼」独立内容包](https://github.com/Chrismick111/MirrorOfSkin/releases/download/v1.3.7/Pilgrimage-Compassion-Skins.zip)。包中包含十个战斗外观、对应头像及模型内的原有动作和音效。

1. **将下载的 `Pilgrimage-Compassion-Skins.zip` 改名为 `善意的巡礼-战斗外观.zip`。** 工作台按原包名关联外观编号和头像。
2. 在工作台点「导入本地外观」，直接选择改名后的 ZIP，无需解压。
3. 打开「添加人格 → 外来人格」，搜索「善意的巡礼」。已导入旧包的玩家也可按相同步骤更新，原有十个外观沿用原编号，自己上传的头像优先显示。

## 整理章节、名称和头像

- **管理章节**：在「添加人格」中展开「管理章节与批量归类」，可以新建章节、自定义章节名、上传封面，或搜索并勾选要移入的外观。将外来外观移入章节后，可在该章节的「添加人格」列表和「全部外观」中找到；恢复自动归类后，条目会回到原分类。
- **修改外观名称**：点击外观行右侧的铅笔。新名称可用于搜索，清空后恢复默认名称。
- **更换头像**：在池中右键外观，选择上传图片或恢复默认图片。导入包提供头像时，重置自选头像后会重新显示包内图片。首次使用时缺少游戏头像，可点击工作台的「重新获取资源」。

## 文件存在哪里

| 内容 | 默认位置 |
| --- | --- |
| 新导入的外观模型 | `FaustLauncher/addons/MirrorOfSkin/imported-appearance/<压缩包名>/`，跟随启动器所在磁盘 |
| 个人设置、规则集、方案、章节、头像、索引及独立语音库 | `%APPDATA%\FaustLauncher\MOS_data\` |
| 战斗运行日志 | `%APPDATA%\FaustLauncher\MOS_data\native_runtime.log` |

移除外观时，可以在「添加人格」中删除对应条目。按包管理时，也可以删除对应的模型子文件夹，再回到工作台刷新。删除插件后重装，若看到旧外观显示「模型缺失」，重新导入原压缩包可恢复原编号和已选规则。

## 模组作者与问题反馈

制作外观包时，可在包根目录的 `README.md` 写明作者全称，并用「演示视频」「作者主页」「项目仓库」等文字标注链接。如果同一包内的外观分别由不同作者制作，可在各自的外观目录中提供独立 README。依赖和致谢链接请放在相应章节。

作者可在 `mos-skin.json` 中声明攻击、拼点、守备及语音归属，也可通过 `mos-portraits.json` 随包提供头像。格式和示例见[外来外观包动作配置](docs/foreign-appearance-motion.md)。

反馈导入问题时，请附插件版本、压缩包名称和展开后的导入提示。反馈战斗表现时，请注明佩戴的人格、外观、技能，以及问题发生在第几枚硬币或哪一次拼点；遇到朝向问题时，也请指出角色和敌人各在哪一侧。[提交问题](https://github.com/Chrismick111/MirrorOfSkin/issues)
